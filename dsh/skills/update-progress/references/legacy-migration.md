# Legacy Migration

仅用于迁移尚不含 `Current State` 章节的旧格式 progress 或 `HANDOFF.md`。

1. 按内容证据而非 mtime 调和旧 progress 与 `HANDOFF.md`。保留未知和冲突；仅当冲突会影响决策时提问。不得把当前格式的 `PROGRESS.md` 与过期 handoff 重新合并。
2. 将历史移入 worklog，保留原始日期、结果和证据。日期缺失或范围模糊时，保留原标签，并在迁移日期下建立明确标注的 imported 章节；不得编造精确日期。保留已有每日条目，跳过已迁移内容。
3. 先写入并验证目标条目与链接，再处理来源内容。通过条目数或原文比对确认内容已保留；`PROGRESS.md` 只保留粗粒度 milestone 和当前状态。重复迁移不得产生重复内容或覆盖人工记录。
4. 仅在用户授权清理且内容已验证保留后删除旧来源。Hooks 不读取、迁移或创建记录；不得为旧插件维持双份写入。
